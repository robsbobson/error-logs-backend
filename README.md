# Node Backend Starter

Minimalist Node.js backend application using TypeScript.

## Requirements

- Node.js (latest LTS version)
- npm or yarn

## Installation

```bash
npm install
```

## Configuration

Create a `.env` file in the root directory of the project and add:

```
PORT=3000
```

## Running

### Development Mode

```bash
npm run dev
```

### Production build and execution

```bash
npm run build
npm start
```

## Scripts

- `npm start` - starts the production application
- `npm run dev` - starts the application in development mode with automatic reloading
- `npm run build` - compiles the TypeScript code to JavaScript
- `npm run lint` - checks the code using ESLint
- `npm run format` - formats the code using Prettier
